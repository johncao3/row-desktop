# ROW 1.06 · 公开测试版

发布日期：2026-10-28。

本次加入当前用户安装器，包含桌面/开始菜单入口和 Windows 卸载项；升级保留用户设置，卸载保留自选、桌面恢复数据及当前卸载器。

# ROW 1.05 — 发布说明草稿

**内部草稿。数据、图标和软件分发许可未完成，不发布本说明对应的下载。**

计划说明：

- Windows 桌面顶部单行信息栏，五个位置自由选择。
- 日夜主题、托盘控制、详情面板、自选设置。
- 工作区预留，桌面图标避让与条件恢复。
- 球队跟随、赛事详情、行情采样走势，体育内容居中与队徽重试。

正式发布时按实际获准的数据源填写，不将现有原型功能全部直接承诺。

待填写：经过验证的 Windows 版本、获准数据源、刷新/延迟、软件许可、已知限制、是否签名、最终 ZIP 文件名与 SHA256。当前开发程序未签名。

安装：下载 ZIP，解压到用户可写文件夹，退出旧版本，再打开 ROW.exe。

卸载：先从托盘正常退出，确认桌面恢复，再移除软件文件夹。保存自选前可备份 settings.json，但不要分享该文件或桌面位置备份。

## 先区分三件事

1. 分发我们编写的 Windows 软件。
2. 每个用户的客户端自动连接第三方接口并在屏幕展示数据。
3. 由我们缓存、集中转发、公开下载或出售第三方数据。

当前原型是第 2 种，不运营第 3 种服务器，但仍须确认自动调用、终端展示、免费公开分发客户端的许可。接口无密钥、公开可读、注明出处、免费软件、用户自行联网，均不能单独证明授权成立。

## 收到答复后如何判断

书面许可至少应覆盖：具体接口、免费客户端公众分发、用户设备直连、终端显示、允许地域、署名、缓存、限流、用户规模、收费/赞助影响，以及图标是否另计授权。只说“API免费”或只获个人测试许可，不足以把本表改为通过。

未拿到某项授权，不代表项目永远无法发布：可以移除该来源、换成明确允许该用途的服务，或取消相应数据功能。用户输入个人 API 密钥也不能自动解决分发或展示权问题。

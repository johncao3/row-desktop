# ROW · 时刻在场

**工作在手，动态在眼前。**

ROW 是一款 Windows 桌面顶部信息栏，把你关注的市场与比赛，放进一条简洁的视线里。

写文档、看报表、处理日常任务时，不必反复切换行情和比分页面。抬眼即可查看关注内容，需要更多信息时，再点击展开详情。

## 五个位置，由你决定

五格可以全部放行情，也可以混搭股票、币种与比赛。原型支持 A 股、美股及指数、加密资产、NBA 与足球赛况；公开版本的最终数据覆盖，以获准接入的服务为准。

## 一眼看比分，点开看过程

- 篮球：队徽、比分与比赛状态；展开查看各节和加时比分、当前分差，以及程序最近观察到的比分变化。
- 足球：查看比赛阶段及数据源返回的进球、红牌事件。
- 行情：查看价格、涨跌、报价时间与本次运行期间积累的采样走势。

可以固定一场比赛，也可以跟随球队。当前球队跟随检查已启用联赛的近三日赛程，优先显示进行中比赛，保留当天完场结果，再转向下一场。

## 留在桌面，少打扰一点

40 DIP 单行布局，白天浅色、夜间深色。体育内容居中，三位数比分完整展示；缺失队徽使用图形占位。Windows 工作区为信息栏预留位置，提供托盘控制及 Ctrl+Alt+B 快捷隐藏。

比分变化用短暂的橙色细线提示。没有声音或系统通知轰炸，详情按需展开。

## 清楚交代信息的时间

当前原型每 60 秒请求数据，各接口完成后分别更新。它提供定时快照，不是逐笔行情或视频直播，也不能保证捕捉每一次中间得分。走势图从程序启动后开始积累，不是完整的历史分时图。

## 版本与下载

当前原型版本为 **1.06**。公开下载正在准备中，尚未开放。

正式下载将提供 Windows 压缩包、版本说明和 SHA256 校验值。最终数据源、许可范围、兼容性及签名情况会在发布时明确列出。

无 ROW 账号系统、广告或自建遥测服务。设置保存在本机；数据请求会直接发送给相应服务提供方。详见 [隐私说明](../PRIVACY.md)。

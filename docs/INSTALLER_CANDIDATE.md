# ROW 1.06 · 使用说明

本安装包是维护者本地验证候选版，尚未批准公开下载。

安装到当前用户的 LocalAppData/Programs/ROW，无需管理员权限。创建桌面和开始菜单快捷方式，并注册 Windows 卸载入口。安装默认不启动程序，不注册开机启动。

我的关注：搜索股票、币种、球队或比赛，点 ＋ 添加；最多五项，满额才询问替换。点 − 删除，拖动 ≡ 或点击 ↑ 排序，即时保存。外观、屏幕、联赛在偏好设置中。

Ctrl+Alt+B 显示/隐藏顶部栏；退出请使用右下角托盘菜单。更换安装目录或升级前请先正常退出，让桌面位置恢复。

安装器保留已有自选与用户数据；未知来源的非空目标目录会拒绝覆盖。旧便携版的个人设置不会自动导入，请先退出旧版，备份 settings.json 后自行复制到新目录。

数据每60秒轮询，可能受行情源、交易时段、网络和赛事覆盖影响。股票价格、币种报价与体育数据不是交易或逐球直播保证。跟随球队来自已启用联赛的近三日赛程。

在 Windows 设置的应用列表中选择 ROW 卸载，或在安装目录运行 Uninstall.exe /uninstall。卸载移除应用文件及对应快捷方式，保留 settings.json、桌面布局恢复数据、日志和当前卸载器；确认无需恢复后可自行删除剩余目录。

第三方数据、队徽公开使用范围待确认。本安装包未签名。若 Windows 或组织策略阻止运行，请保留拦截信息供维护者核实，不要求关闭安全防护。

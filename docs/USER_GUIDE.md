# ROW 1.06 · 安装与使用

1. 从旧版 ROW 的右下角托盘菜单选择退出。
2. 运行 ROW-1.06-Setup.exe，点击“安装 / 更新”。默认不自动启动。
3. 使用桌面或开始菜单中的 ROW 图标打开。

安装到当前用户 LocalAppData/Programs/ROW，无需管理员权限，不注册开机启动。要求 Windows 10/11 与 .NET Framework 4.5 或更新版本；目前仅在开发机完成验证，安装包未签名。系统或组织策略可能限制运行，不要求关闭安全防护。

## 我的关注

搜索股票、币种、球队或比赛，点 ＋ 添加；最多五项，满额才询问替换。点 − 删除，拖动 ≡ 或点击 ↑ 排序，立即保存。外观、屏幕和足球联赛在偏好设置中。

股票可输入 600519、sz000001、AAPL 等代码后查询。更多币种加载后可搜索。球队来自已启用联赛的近三日赛程；可跟随球队或固定单场比赛。Ctrl+Alt+B 显示/隐藏顶部栏；退出使用托盘菜单。

## 数据与隐私

每60秒轮询；显示快照可能延迟或漏过中间得分。当前数据源为腾讯行情、CoinLore 与 ESPN，队徽来自 ESPN 图像服务器。客户端直接请求提供方，无 ROW 账号、广告或自建遥测。第三方使用范围尚在核对，未宣称获官方合作或授权。

价格走势图只积累本次启动后的有效采样，不是完整历史分时图。自选等配置保存在安装目录；股票请求范围包括配置中保留的代码，可能超过顶部五项。

## 升级和卸载

安装器保留已有用户数据；未知非空目标目录会拒绝覆盖。旧便携版不自动迁移，先备份 settings.json，再按需复制到安装目录。

从 Windows 的应用列表卸载 ROW，或运行安装目录中的 Uninstall.exe /uninstall。请先正常退出，让桌面位置恢复。卸载删除应用文件与对应快捷方式，保留 settings.json、桌面布局恢复数据、日志和当前卸载器；确认无需恢复后可以手动删除剩余目录。

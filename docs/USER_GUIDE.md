# ROW 1.05

本版增加篮球、足球、行情详情，并调整选择比赛的窗口流程。

## 使用

- 退出旧版后打开 ROW.exe。Ctrl+Alt+B 显示/隐藏顶部栏。
- 选内容 → 添加到顶部 → 选择位置 → 保存。球队跟随先选球队，再选位置；取消不会改动已选内容。
- 点击顶部任意内容打开详情，点击其他窗口关闭。详情打开时每两秒检查本地最新数据；联网仍为每 60 秒一次。

## 详情

| 篮球 | 足球 | 行情 |
|---|---|---|
| 各节比分、加时比分、当前分差、最近观察到的比分变化 | 比赛阶段、接口返回的进球和红牌事件（含乌龙球、点球标识） | 当前价格、涨跌、源报价时间、本机接收时间、采样走势图 |

篮球的最近变化是两次快照之间的差异，不是逐球记录；首次打开和断线重连不会凭旧数据生成变化。缺失的节比分显示 —。

足球事件仅显示接口明确返回的内容；缺失事件数据与当前未返回进球/红牌分别说明，不由总比分反推事件。

走势图从本次启动后开始积累，至少两次有效报价后显示，最多保存每个代码 180 个采样点。股票相同源报价时间不重复加入；币种缺少源时间，按本机接收时间采样。网络失败不加入点，间隔超过 150 秒不连线。关闭程序后清空，不代表完整日内分时图或历史 K 线。

## 故障处理

本次未在可读取的日志中找到用户报告的崩溃堆栈，不能断言原始原因已确认。已替换选择场次菜单中同步销毁自身的高风险流程，改用独立选择窗口；修正控制中心关闭回调引用其他窗口的问题，并记录未处理的界面异常到 crash-log.txt。

如再遇异常，记录发生时的操作步骤及对应 crash-log.txt。设置和已选内容保存在同目录 settings.json。

本版供本地试用，未上传 GitHub 或发布公开下载。数据源仍为腾讯行情、CoinLore、ESPN。

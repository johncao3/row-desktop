# ROW 1.06 · 我的关注

将原先先选位置、再选分类的操作合并为一份关注列表。

- 搜索股票、币种、球队或比赛后点击 ＋，自动追加到末尾。
- 满五项时才询问替换对象；删除后自动补位。
- 拖动 ≡ 或点击 ↑ 排序，修改即时保存；保存失败保留原列表。
- 可清空列表，点击顶部空位重新添加。
- 外观、显示屏幕及联赛迁入独立偏好设置。

验证通过：编译、数据逻辑、自选组合、交互回归、体育比分宽度和浅深色预览。拖放验证使用控件模拟事件，尚未完成真实鼠标端到端验证。本次没有复测外部接口的网络或延迟。

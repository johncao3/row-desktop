# ROW 1.05

- 队徽加载取消每批前 12 场限制，优先请求顶部内容，其余比赛也会加载。失败后至少隔一分钟重试；NBA scoreboard 图片地址失败时尝试普通图片地址。接口缺少地址但有球队 ID 时补全 ESPN 地址。
- 队徽不可用时使用中性图形占位，不再显示两字队名。完整队名保留在悬停说明及详情中。占位图不是官方队徽，网络或源文件问题仍可能导致暂时缺图。
- 篮球与足球内容按实际总宽度居中，比分区域按文字测量，支持三位数对三位数。空间不足先精简时间显示，极窄格子省略时间，悬停仍能查看完整赛况。
- 本仓库保存源码；请使用 build.ps1 本地构建，退出旧版后启动生成的 ROW.exe。个人设置不上传仓库。

验证：构建、基础测试、比赛选择交互回归通过；800/1024/1440/1920 宽度的 128 : 123 与足球补时渲染通过，人工检查 800 和 1440 图片无比分省略。sports-*.png 使用测试比分及中性占位图，不代表真实比赛或实际队徽加载结果。本轮未逐一联网验证所有球队图片可用性。

# ROW · 时刻在场

一条放在 Windows 桌面顶部的信息栏，让关注的市场与比赛留在视线里。

**状态：源码预览版；EXE 公开下载尚未开放。**

当前原型版本：**1.06**。详细变化见 [1.06 更新说明](docs/UPDATE_1.06.md)。

[软件介绍](docs/INTRODUCTION.md) · [公开发布准备](docs/PUBLIC_LAUNCH_PLAN.md)

原型已实现五位置自由组合、单行布局、日夜外观、系统托盘和桌面避让。实时行情、体育数据及队徽的对外使用权限仍在核查，当前源码中的数据适配器不代表已经获得分发许可。请勿把开发构建当作公开获授权的正式版传播。

## 已完成的原型功能

- 40 DIP 单行，五个位置可自由组合股票、币种或比赛。
- 日夜主题、悬停详情、托盘控制、Ctrl+Alt+B 显示与隐藏。
- Windows AppBar 为其他窗口预留空间。
- 桌面图标避让及条件恢复；用户手动改过的位置不会强制复原。
- 统一“我的关注”列表：搜索后直接添加，删除自动补位，拖动排序，即时保存。
- 满五项才选择替换；外观、屏幕和联赛放在独立偏好设置。
- 简化场次选择、球队跟随、比分变化提示与源报价/接收时间区分。
- 篮球节比分和分差、足球进球与红牌事件、运行期间的行情采样走势图。
- 体育内容居中，三位数比分自适应宽度；队徽优先加载、失败重试及图形占位。

## 本地开发

Windows、.NET Framework 4.x 与 PowerShell。编译器由 `build.ps1` 从 Windows Framework 目录查找。

```powershell
.\build.ps1
.\scripts\Test-Local.ps1
```

本地检查只运行合成数据测试，不请求行情、不移动桌面图标。网络与桌面实测需要开发者另外主动运行，见 [开发与验证](docs/DEVELOPMENT.md)。

构建会生成未签名的开发 EXE，当前不应上传到 Releases。

## 隐私与反馈

无 ROW 账号系统、广告或自建遥测服务。联网适配器会直接向数据提供方发送行情代码与网络请求；桌面布局备份保存在本机，不发送给数据源。[详情](PRIVACY.md)

反馈前请去掉日志中的本地路径、自选内容及其他个人信息。不要上传 `settings.json` 或 `desktop-layout-backup.json`。

本项目与行情提供方、球队、联盟没有已确认的合作或背书关系。
